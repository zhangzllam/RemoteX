## Procedure

For each physical run, record both endpoint hardware/OS, encoder profile, Control,
Relay and optional standards-compliant STUN endpoints, NAT/firewall notes, and
whether UDP is allowed. Confirm that Direct handshake remains session/role/nonce
bound, Relay cannot decrypt payloads, explicit Disconnect never reconnects, and
an unreachable Direct path produces a normal Relay session rather than an error.
