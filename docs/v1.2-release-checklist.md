# RemoteX v1.2 release checklist

## Source and behavior

- [ ] Unified server migration tested with no settings, matching settings, one
  custom setting, and two conflicting custom settings.
- [ ] Production build has no localhost default.
- [ ] First-run check, retry, change-server, save, set-up-later, and
  run-setup-again paths tested without starting device registration.
- [ ] Existing configured v1.1 users skip first-run setup.
- [ ] Controller-only use can connect after server setup without local-device
  registration, and Home does not show a registration prompt.
- [ ] Interactive approval, independent permissions, visible session state,
  local disconnect, DPAPI secrets, E2EE, and file-root confinement regressions
  pass.
- [ ] Binary video Channel, base64 fallback, latest-frame dropping, input focus,
  canvas aspect ratio, and `Ctrl+Shift+D` diagnostics tested.

## Automated gates

- [ ] `cargo fmt --all --check`
- [ ] `cargo clippy --workspace --all-targets --all-features -- -D warnings`
- [ ] `cargo test --workspace --all-features`
- [ ] `pnpm --dir apps/desktop/ui install --frozen-lockfile`
- [ ] `pnpm --dir apps/desktop/ui build`
- [ ] `pnpm --dir apps/desktop/ui benchmark:video`
- [ ] `cargo audit` with only the documented unreachable exception
- [ ] `pnpm --dir apps/desktop/ui audit --prod`
- [ ] `scripts/validate-release.ps1` and artifact mode pass
- [ ] Windows desktop and sidecar use the GUI PE subsystem

## UI acceptance

- [ ] 1280x720, 1366x768, and 1920x1080 layouts have no clipped critical
  action, unintended overlap, or unusable scroll region.
- [ ] Keyboard-only navigation has logical order and visible focus.
- [ ] Status and toggles do not rely on color alone; normal text contrast is at
  least 4.5:1 and large text/UI boundaries at least 3:1 where applicable.
- [ ] Reduced-motion mode removes nonessential animation.
- [ ] Home uses user language: This device, Connect, Recent; implementation
  terms are restricted to advanced diagnostics and maintainer documentation.

## Release integrity

- [ ] Annotated signed tag verifies with the protected release key.
- [ ] Tag, Cargo, UI, Tauri, installer, and updater manifest versions match.
- [ ] Installer updater signature and SHA-256 verify.
- [ ] Authenticode verifies when certificate secrets are configured.
- [ ] Release notes include highlights, upgrade notes, security behavior,
  known limits, and self-hosting changes.
- [ ] No private key, PFX, password, token, session data, or payload content is
  present in source, artifacts, logs, or release notes.
