# Security policy

## Supported versions

Security fixes are provided for the latest V1 release.

## Report a vulnerability

Use GitHub's **Security → Advisories → Report a vulnerability** flow for this
repository. Do not open a public issue with exploit details, credentials,
private keys, session tokens, or user data. Include the affected version,
component, reproduction steps, impact, and any suggested mitigation.

Please test only systems and data you own or are explicitly authorized to use.
