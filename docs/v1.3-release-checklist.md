# RemoteX v1.3.0 release checklist

Status: publication authorized on 2026-09-10. The signed-tag release workflow
performs final Windows/Linux builds and creates signed updater assets.

## Required automated gates

- [x] Workspace, Tauri, and frontend versions agree at 1.3.0.
- [x] `cargo fmt --all -- --check`.
- [x] `cargo clippy --workspace --all-targets --all-features -- -D warnings`.
- [x] `cargo test --workspace --all-features`.
- [x] Frontend TypeScript and production Vite build.
- [x] Windows Agent and Desktop release builds use the GUI subsystem.
- [x] Local NSIS installer generated without updater signing metadata.
- [x] `cargo audit` and `pnpm audit --prod` immediately before publication.
  Rust reported maintenance/yanked/unsoundness warnings; frontend production
  dependencies reported no known vulnerabilities. See release notes.
- [ ] Signed annotated `v1.3.0` tag verified by the release workflow.
- [ ] Signed updater artifacts generated using the protected private key.
- [ ] Optional Authenticode signature and timestamp verified.

## Required manual network/release gates

- [ ] Same-LAN Direct session, permission prompt, input release, clipboard, and
  resumable file transfer.
- [ ] Public-network server-reflexive Direct using a controlled STUN endpoint.
- [ ] Forced Relay remains E2EE and immediately usable.
- [ ] Direct interruption recovers through Relay; explicit Disconnect never
  reconnects.
- [ ] Wi-Fi/VPN/hotspot transitions follow the network matrix.
- [ ] Diagnostics and connection quality reviewed in English and Simplified
  Chinese, dark/light/system modes, and 1280×720, 1366×768, 1920×1080.
- [ ] Install/upgrade/uninstall tested; Start menu, Desktop and taskbar icon
  caches checked on a clean Windows user profile.

The absence of completed physical-network rows prevents claiming measured NAT
success rates or real end-to-end performance numbers in release notes.
