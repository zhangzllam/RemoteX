# RemoteX v1.3.2

## 下载和使用

- Windows x64：下载下方 Assets 中的 **RemoteX_1.3.2_x64-setup.exe**。
- Linux：下载 **RemoteX-linux-agent-x86_64.tar.gz**，按仓库 Linux Agent 文档配置。
- `.sha256` 为校验文件，`.sig` 和 `latest.json` 用于应用内签名更新。
- 普通用户无需下载 Source code。

在两台 Windows 电脑上安装 RemoteX。在被控电脑开启「允许远程访问」，
获取设备 ID 和密码；在控制电脑输入这两项后点击连接。键鼠、剪贴板和
文件权限由被控电脑分别控制。升级前从托盘彻底退出旧版。

## 本次更新

- 修复 Linux Agent 对连接路径控制消息的兼容性，并在发布流程中执行 Linux 原生测试。

- 固定发布使用的 Rust 版本，避免云端工具链自动升级导致发布检查变化。

- 重新整理主页的本机访问和主动连接区域，完善中英文、深浅色和小屏布局。
- 首次开启远程访问自动生成连接密码，支持随机换密、自定义、显示和复制；
  可选择每次手动确认，密码在本机使用 Windows DPAPI 保护。
- 修复启动项不存在时无法开启远程访问的问题。
- 修复应用图标留白过大，以及任务栏仍引用旧分组图标的问题。
- 增加最近设备搜索、移除和撤销，防止连接本机及切换设备后误用旧密码。
- 改进直连候选发现、中继优先可用、连接恢复、视频自适应及连接质量诊断。
- 内置项目默认 IP 控制入口和证书验证，统一桌面端及 Agent 的连接配置。

## 验证与已知限制

全工作区静态检查和自动测试、前端构建、60 组界面组合检查及公网
Control/Relay 就绪与证书检查已通过。两台真实电脑跨网络的完整画面、
输入及 Wi-Fi/VPN 切换仍需实测，不宣称所有 NAT 场景均已通过。

依赖审计完成：前端生产依赖未报告已知漏洞；Rust 审计保留停止维护、
yanked 以及上游 glib 的 unsoundness 提示，未隐藏这些结果。
更新签名用于验证安装包完整性，不等同于 Windows Authenticode 发布者认证。
